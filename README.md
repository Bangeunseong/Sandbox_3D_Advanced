# Inventory UI Demo

## Overview


이 게임은 캠프를 진행하면서 이전에 배운 내용을 가지고 만든 인벤토리 UI이다. 여기에는 조작이 가능한 캐릭터가 존재하는데 이는 FSM을 이용한 State마다 수행할 역할을 분리하여 여러가지 행동 및 애니메이션이 자연스럽게 출력된다. UI는 전체적으로 Intro, Loading, Main으로 나뉘어 씬마다 다른 UI가 적용된다. 

## Control Scheme


**WASD : 이동**

**Left Shift : 달리기**

**C : 수그리기**

**마우스 왼쪽 클릭 : 공격하기(공격콤보 O)**

**T : 춤추기**

**E : 랜덤 아이템 추가**

**R : 경험치 추가(10 씩)**

## Loading Scene


![스크린샷 2025-06-11 091500.png](./Images/%EC%8A%A4%ED%81%AC%EB%A6%B0%EC%83%B7_2025-06-11_091500.png)

Loading Scene에서는 비동기적으로 씬을 불러오는 Task와 Main 씬에서 필요한 ScriptableObject, JSON 정보들을 불러오는 Task를 실행한다. 이러한 과정을 Slider의 값 변화를 통해 진행상황을 알 수 있다. 로딩이 모두 끝날 시 아무 키나 누르면 Main 씬으로 전환된다.

## Main Scene


![스크린샷 2025-06-11 091522.png](./Images/%EC%8A%A4%ED%81%AC%EB%A6%B0%EC%83%B7_2025-06-11_091522.png)

Main Scene에서는 캐릭터가 하나 존재하고 맵이 있는 것을 볼 수 있다. WASD를 이용하여 조작이 가능하고 마우스를 이용해 시야를 조정할 수 있다. 왼쪽 Shift를 눌러 캐릭터를 달리게 할 수 있으며 C를 눌러 캐릭터가 수그리게 할 수 있다. 마우스 왼쪽 클릭을 누르면 공격을 하는데 총 3번의 콤보를 넣을 수 있다. M키를 누르면 Main UI가 나온다.

Main UI에서 Status 버튼을 누르면 현재 스텟을 볼 수 있다. 이는 전부 동적으로 생성이 된다. StatType의 종류에 따라 동적으로 이름과 아이콘 스텟을 설정한다. 인벤토리에서 장착한 장비의 스텟에 따라 스텟이 변하는데 수명과 관련된 스텟은 최대 체력만 변하지 실제 체력은 변하지 않기에 최대 체력을 변경하면 실제 체력은 아이템으로 채우도록 설계를 하였다. 

Inventory 버튼을 누르면 Inventory UI가 나타나는데 아이템을 클릭하면 아이템 정보와 장착을 할 지 버릴 지 버튼이 나타난다. 이 버튼은 아이템의 종류에 따라 바뀌는데 장착이 가능한 아이템은 장착관련 버튼이 나타나고 소모 아이템은 사용관련 버튼이 나타난다. Inventory 내 아이템들은 아이템이 추가되거나 버려질 때 자동으로 정렬이 되며 정렬 방식을 선택할 수 있다. 인벤토리 내부 아이템의 개수를 알 수 있는 텍스트 옆에 3개의 버튼이 있는데 기본 정렬 방식, 희귀도 우선 정렬 방식, 가격 우선 정렬 방식 중 선택할 수 있다.
